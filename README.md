# AI Procurement Auditor

## Описание проекта

**AI Procurement Auditor** — веб-приложение на Django для интеллектуальной проверки бухгалтерских и закупочных документов с использованием OCR, набора правил и технологий искусственного интеллекта.

Проект разрабатывается как MVP с последующим расширением функциональности.

---

# Цель проекта

Создать систему, которая автоматически проверяет документы до передачи их бухгалтеру и выявляет потенциальные ошибки.

Планируется поддержка:

- счетов;
- УПД;
- товарных накладных;
- других первичных бухгалтерских документов.
